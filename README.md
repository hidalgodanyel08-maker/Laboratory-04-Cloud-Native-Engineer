# Laboratory 04 - The Cloud-Native Engineer

## Mission Overview

This laboratory activity introduces containerization and explains how containers differ from traditional Virtual Machines. Using the KillerCoda Docker environment, I practiced basic Docker commands and deployed an Nginx web server inside a container.

## Objectives

- Differentiate Virtual Machines and containers.
- Access a Docker-enabled Linux environment.
- Execute fundamental Docker CLI commands.
- Pull and run an Nginx container.
- Map a host port to a container port.
- Manage the container lifecycle.
- Document Docker operations using Markdown.
- Maintain my GitHub Cloud Computing Portfolio.
